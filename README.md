# BetHub rebuild

Planning workspace for rebuilding BetHub from the ground up.

The current tool (BetHub v2) is still running in `~/Desktop/Projects/bethub-v2/` and is used daily. This folder is for designing the replacement, not for code.

**At session open, read:** `work_in_progress.md`. That is it.

Open `vision.md` or `architecture.md` only if the session needs them.

**Files in this folder:**
- `vision.md` — what the rebuilt system is for
- `architecture.md` — the v3 design (slow-changing reference)
- `decisions.md` — every architectural decision, numbered
- `work_in_progress.md` — current state, updated each session
- `sessions/` — one short note per session
- `diagrams/` — picture files referenced from architecture.md

**What is deliberately NOT here:** anomaly logs, patch logs, status files, separate conventions docs. v3 governance is decisions and current state. Nothing else.
